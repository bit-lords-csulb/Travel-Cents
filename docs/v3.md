# AI Chat Overhaul Plan v3

Supersedes v2. Goal: reframe `ai_trip_chat` as a **quick idea engine** — the user opens it to grab a trip, a place, or a single activity they can run with in under a minute. Every card is image-led, and every card is a real, reusable object the rest of the app already knows how to render.

---

## Phase 0: Completed Foundations (v2)
*Completed deliverables from the original overhaul plan.*

*   **Hotspot Seed Catalog (1A):** Fully implemented catalog of curated trip seeds in `AiCuratedTripCatalog.kt`.
*   **Structured Intake (2A-2D):** Schema-driven intake orchestrator, traveler profile reduction, and multi-turn intake UI are functional.
*   **Basic Curated Logic (1B/1C):** The ability to render curated rows and refine them (adjusting duration/vibe) via the AI pipeline is live.

---

## Phase 1: Curated Editable Trip Starters

### Phase 1B: Visual Refresh & Image Strategy
**Status: Pending.** Move from text-only cards to a high-fidelity, image-led layout.

**Image Requirements:**
*   **Curated Trips / City Cards:** Use **Wikimedia hero images** via `DestinationImageRepository`. These represent the "vibe" of a city or country.
*   **Restaurant / Activity Cards:** **Must use venue-specific images** from Yelp/Ticketmaster. Do not use generic city photos for specific businesses.

**Deliverables:**
- [x] `AiCuratedTripStarter.heroImageUrl: String?` populated via `DestinationImageRepository.resolveDestinationImage(destination)`.
- [x] `AiCuratedTripCard` redesigned: 260dp × ~320dp, 4:5 image, vertical scrim, overlaid title + destination + duration pill.
- [x] `AiChatViewModel` kicks off image resolution when a curated row is added to the stream.

### Phase 1D: Curated Starter → Current Trip Preview
**Goal:** Reuse the existing `CurrentTripScreen` to show a curated starter as a full trip, without committing it to Firestore.

- [x] `AiCuratedTripToItineraryMapper` (starter + refinement state → `Itinerary` + `List<TravelEvent>`).
- [x] `CurrentTripViewModel.PreviewSource` sealed type; preview path skips Firestore listeners.
- [x] `current_trip_preview` route in `MainScaffold`.
- [x] "Use this trip" logic extracted into `NewTripViewModel.commitItinerary()`.
